# Future Roadmap (V2 & Beyond)

This document catalogs features and capabilities intentionally deferred from V1 for clean architectural focus, to be considered for future V2 / V3 releases.

## V2 Planned Capabilities

1. **Student Cloud Accounts & Sync**:
   - Optional student sign-up via Email/Magic Link or Google/GitHub OAuth.
   - Encrypted cloud persistence of resumes with multi-device synchronization.
   - Version history and changelog per resume draft.

2. **Resume Import Engine**:
   - High-accuracy PDF and DOCX parsing into structured `ResumeData`.
   - LinkedIn profile export import via structured JSON/HTML parser.

3. **Advanced AI Workflow**:
   - AI Cover Letter generator matched to specific Job Descriptions.
   - AI Interview question generator based on customized resume bullet points.
   - Multilingual resume translation and localization.

4. **Analytics & Performance Tracking**:
   - Student application tracking dashboard (applied jobs, resume version used, interview status).
   - Anonymous aggregated template popularity metrics for administrators.

5. **Advanced Export & Integrations**:
   - Direct export to Google Drive / Dropbox.
   - 1-click apply integration with supported university job portals.
