## 3. Shared vs Custom Architecture Plan

### A. Normalized ResumeData Contract
All 28 templates consume the exact same normalized `ResumeData` object, guaranteeing 100% loss-free template switching.

### B. Shared Component Library
- `ContactItem` / `ContactBar`: Handles responsive separator styling (pipe `|`, bullet `•`, diamond `⋄`, icon badges)
- `SectionHeading`: Handles rule styles (underline, bottom border, colored text, all-caps, small-caps)
- `ExperienceEntry`: Company, role, location, date range, and bullet points
- `EducationEntry`: Institution, degree, field, GPA/percentage, coursework, location, date
- `ProjectEntry`: Project title, subtitle/tech stack, links (GitHub/Live), bullet points
- `SkillsCategoryGrid`: Categorized skills chips, comma-separated lists, proficiency levels
- `PlacementAcademicTable`: 4-column structured academic table for IIT/IIIT/NIT placement formats (`template_20`)
- `DeedySidebarLayout`: Asymmetric two-column grid layout for `template_15` (Deedy LaTeX style)
